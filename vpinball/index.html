Visual Pinball for iPhone: a phone-first build

Visual Pinball X on an upright iPhone, built for the phone first: tables that fill the screen, vivid looks and flippers under your thumbs.

No tables are included except Visual Pinball's own example table: bring your own .vpx tables.

Install

Easiest, in SideStore or AltStore (Classic): add the source, then install the app from it. Updates come the same way.

Cool features

  • Tables fill an upright phone screen, seen head on like a real machine, instead of a view made for a wide monitor.
  • Five looks for bright, vivid play (Vivid, Punchy, Vivid Bright, Arcade, Daylight) or the table's own, switched live from the in-game menu.
  • Thumb-friendly touch: each flipper gets its whole half of the lower screen, nudges on the sides, and nothing in between that tilts the table by accident.
  • One tap on START puts in a coin and starts, and on an iPhone games start by themselves.
  • The score display at the top, see-through; hold it to move, resize or fade it.
  • Autoplay: the table plays itself until you touch the screen.
  • 60 or 120 FPS on 120 Hz screens.
  • Easier importing: whole folders, an Import folder in Files, ROMs put where they belong, a warning when a ROM is missing, and fixed scripts fetched from the community's vpx-standalone-scripts.

Visual Pinball's example table, drawn by this build running on a computer at an iPhone's screen size, not from an iPhone.

This is an unofficial beta, made by one fan on top of the Visual Pinball team's work, and only a few tables have been tried. Expect bugs, and sorry for the ones you meet. There's no online or Wi-Fi multiplayer (Visual Pinball doesn't have it either); taking turns on one phone is up to each table and hasn't been tried here. It uses the same app ID as the official app, so the two may not install side by side.

Found a bug? Report it here, not to the Visual Pinball team.
